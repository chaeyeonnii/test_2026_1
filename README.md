# 중간고사 퀴즈

컴퓨터구조 · 인공지능기초 · 빅데이터개론 · 자료구조 · 파이썬과학 다섯 과목의 중간고사를 대비하는 모바일 퀴즈 웹앱입니다. 수업 퀴즈·요약정리 예상문제·중간고사 기출을 포함해 1268문항이 챕터별로 나뉘어 있고, 과목별 요약 노트를 함께 볼 수 있습니다.

**배포 주소: https://test20261.vercel.app**

`main` 브랜치에 푸시하면 Vercel이 자동으로 다시 배포합니다.

## 주요 기능

- **비밀번호 잠금**: 처음 접속하면 비밀번호를 입력해야 퀴즈가 열림 (한 번 입력하면 30일 동안 유지)
- **챕터별 출제**: 과목마다 챕터를 골라 풀기, "이 챕터만" 버튼으로 한 챕터만 바로 풀기
- **챕터 섞어 풀기**: 여러 챕터를 체크하면 섞어서 출제
- **출제 조건**: 유형(OX·객관식·단답형·빈칸), 범위(전체·안 푼 문제·틀린 문제·★빈출), 문제 수(5·10·20·30·전부)
- **새 문제 새로고침**: 푸는 중 오른쪽 위 "새 문제"를 누르면 같은 조건에서 다른 문제로 교체
- **채점과 복습**: OX·객관식은 자동 채점, 단답·빈칸은 정답을 보고 맞았는지 직접 체크. 틀린 문제만 다시 풀기
- **오답노트**: 틀린 문제가 자동으로 모임. 정답·해설 확인, 최근/많이 틀린/챕터 순 정렬, 한 문제 또는 전부 다시 풀기, 외운 문제는 노트에서 빼기 (다시 틀리면 다시 올라옴)
- **과목별 요약**: 홈의 "요약 보기" 또는 과목 화면의 "요약" 탭에서 장별 상세 요약(표·코드·★★★ 핵심 상자) 확인, "핵심만 빠르게 보기"로 한 줄 정리도 제공
- **기록 저장**: 푼 기록과 정답률이 브라우저에 자동 저장됨
- **시험일 D-day**: 과목 화면에서 시험일을 정하면 홈에 D-day 표시

## 사용법

1. 배포 주소에 접속해 비밀번호를 입력합니다.
2. 홈에서 과목의 **문제 풀기**를 누릅니다. 요약부터 읽으려면 **요약 보기**를 누릅니다.
3. 챕터를 체크하고 유형·범위·문제 수를 고른 뒤 아래 **N문제 시작**을 누릅니다.
4. 문제를 풀다가 다른 문제로 바꾸고 싶으면 오른쪽 위 **새 문제**를 누릅니다.
5. 결과 화면에서 **틀린 문제 다시** 또는 **새 문제로 다시**를 고릅니다.

문제마다 출처가 표시됩니다: 수업 퀴즈 / 요약정리 예상문제 / 강의 확인문제 / 중간고사 기출 / 추가 문제.

## 로컬에서 실행하기

Python 3와 Node.js(npm)가 필요합니다.

```bash
cd quiz-app
npm run dev
```

브라우저에서 [http://localhost:5173](http://localhost:5173)을 엽니다. `src/`나 `data/`의 파일을 고치면 자동으로 다시 빌드되니 브라우저를 새로고침하면 됩니다. 로컬 실행에는 비밀번호 화면이 없습니다.

### 명령어 (`quiz-app` 폴더에서)

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 (자동 다시 빌드) |
| `npm run build` | `dist/`에 배포용 파일 생성 |

## 문제 추가·수정

`quiz-app/data/<과목>.js`의 `qs` 배열에 한 줄씩 추가합니다.

```js
{t:"mc", c:3, q:"문제", o:["보기1","보기2","보기3","보기4"], a:1, e:"해설"}
```

- `t`: 유형 (`ox` · `mc` · `sa` 단답 · `bl` 빈칸)
- `c`: 챕터 번호, `a`: 정답 (객관식은 0부터 센 번호, OX는 `"O"`/`"X"`)
- `k`: 코드 블록(선택), `s:1`: 빈출 표시(선택)
- `al`: 단답형에서 정답으로 함께 인정할 다른 표현 배열(선택), 예: `al:["과대적합","overfitting"]`

수정한 뒤 `npm run build`를 실행하고 `dist/`까지 함께 커밋하세요.

## Vercel 배포 설정

1. [vercel.com/new](https://vercel.com/new)에서 이 저장소를 Import합니다.
2. Framework Preset은 `Other`로 둡니다 (빌드 설정은 `vercel.json`이 처리).
3. Environment Variables에 `QUIZ_PASSWORD`를 추가합니다. 비밀번호는 공개 저장소에 남지 않도록 코드가 아니라 이 환경변수에만 둡니다.
4. Deploy를 누릅니다.

강의자료 원본(`자료/`)은 저작권 문제로 저장소에 올리지 않습니다.
